**¿Qué genera automáticamente un record? ¿Cuándo conviene usarlo?**

**record**: Pensada para representar datos inmutables de forma simple y concisa

genera:
*Los atributos, es decir, datos inmutables(private final). (ejm: nombre, edad, etc)
*Constructor con esos atributos (Un constructor inicializa los atributos al crear un objeto)
*Metodos propios del objeto (El equivalente a las funciones de C): como equals(), hashCode(), toString(), etc.

Un record en Java genera una clase especial pensada para representar datos inmutables de forma simple y concisa.

¿Cuándo conviene usarlo?

Conviene usar un record cuando necesitamos una clase cuya función principal sea almacenar y transportar datos, y esos datos no deberían modificarse después de crear el objeto.

Por ejemplo, para representar una persona, una coordenada, una fecha, un resultado, etc.
