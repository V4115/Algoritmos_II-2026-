**¿Qué diferencia hay entre el JDK, el JRE y la JVM?**

**JDK**(Java Development Kit): Es el kit de desarrollo. Contiene las herramientas necesarias para crear, compilar y ejecutar programas Java. Por ejemplo, contiene el compilador javac, que transforma el código fuente en **bytecode**, que es un código intermedio que puede ser ejecutado por **JRE** de cualquier máquina. 

**JRE**(Java Runtime Environment): Es el entorno de ejecución. Contiene los componentes necesarios para ejecutar aplicaciones Java, como las bibliotecas java y la **JVM**.

**JVM**(Java Virtual Machine): Es la máquina virtual encargada de ejecutar el **bycode** puede interpretarlo o compilarlo mediante **JIT** al código máquina de la plataforma en la que se está ejecutando.

**JIT**(Just-in-Time compiler): Compila el bytecode al código máquina de la plataforma en la que se ejecuta al momento de ejecución. Además,  puede optimizar el código si detecta que hay partes del código que se ejecuta con frecuencia.
