# Teórica 04

**Diferenciá tipo primitivo y tipo por referencia. Dá un ejemplo de cada uno.**

Los tipos **primitivos** guardan un valor concreto. Por convención los tipos primitivos se escriben con minúsculas. 
Algunos ejemplos de tipos primitivos son: int, double, char, boolean, etc.
ejm: int edad = 34;

Los tipo **por referencia** guardan una referencia a un objeto. Por convención los tipos por referencia empiezan con mayúsculas.
Algunos ejemplos de tipos por referencia son: String, Integer, BigInteger, BigDecimal, etc.
ejm: String nombre = "Pepe";
