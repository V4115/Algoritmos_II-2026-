# Teórica 01

**¿Qué es el bytecode y por qué permite "Write Once, Run Anywhere"?**

Es una serie de instrucciones para una maquina virtual de Java, la cual puede leer esas intruciones independientemente de la maquina en la que se este corriendo, la cual es la que luego traduce el código bytecode al codigo maquina de del sistema en que se este utilizando.
