# 6. Los tres casos del Teorema Maestro, con un ejemplo de cada uno

Para recurrencias de la forma

> **𝑇(𝑛) = 𝑎 · 𝑇(𝑛/𝑏) + 𝑓(𝑛)**, con 𝑎 ≥ 1, 𝑏 > 1

se compara 𝑓(𝑛) con **𝑛^(log_b 𝑎)**.

---

## Caso 1: domina el trabajo de las hojas
Si 𝑓(𝑛) = 𝑂(𝑛^(log_b 𝑎 − ε)) para algún ε > 0, entonces

> 𝑇(𝑛) = Θ(𝑛^(log_b 𝑎))

**Ejemplo:** 𝑇(𝑛) = 8𝑇(𝑛/2) + 𝑛²
- log₂ 8 = 3, y 𝑛² = 𝑂(𝑛^(3−1)).
- **𝑇(𝑛) = Θ(𝑛³)**.

---

## Caso 2: el trabajo se reparte parejo en todos los niveles
Si 𝑓(𝑛) = Θ(𝑛^(log_b 𝑎) · logᵏ 𝑛) con 𝑘 ≥ 0, entonces

> 𝑇(𝑛) = Θ(𝑛^(log_b 𝑎) · logᵏ⁺¹ 𝑛)

(con 𝑘 = 0: 𝑇(𝑛) = Θ(𝑛^(log_b 𝑎) · log 𝑛)).

**Ejemplo:** 𝑇(𝑛) = 2𝑇(𝑛/2) + 𝑛 (Mergesort)
- log₂ 2 = 1, y 𝑓(𝑛) = 𝑛 = Θ(𝑛¹).
- **𝑇(𝑛) = Θ(𝑛 log 𝑛)**.

---

## Caso 3: domina el trabajo de la raíz
Si 𝑓(𝑛) = Ω(𝑛^(log_b 𝑎 + ε)) para algún ε > 0, **y** se cumple la condición de regularidad 𝑎 · 𝑓(𝑛/𝑏) ≤ 𝑐 · 𝑓(𝑛) para algún 𝑐 < 1, entonces

> 𝑇(𝑛) = Θ(𝑓(𝑛))

**Ejemplo:** 𝑇(𝑛) = 2𝑇(𝑛/2) + 𝑛²
- log₂ 2 = 1, y 𝑛² = Ω(𝑛^(1+1)).
- Regularidad: 2 · (𝑛/2)² = 𝑛²/2 ≤ ½ · 𝑛². ✔
- **𝑇(𝑛) = Θ(𝑛²)**.
