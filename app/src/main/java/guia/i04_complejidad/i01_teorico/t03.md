# 3. ¿Cómo se calcula la complejidad de dos bucles anidados? ¿Y de uno que hace `i *= 2`?

## Bucles anidados
Se **multiplican** las cantidades de iteraciones (si son independientes) o se **suma** el trabajo de cada iteración externa (si el interno depende del externo).

```python
for i in range(n):        # n veces
    for j in range(n):    # n veces
        operacion()       # O(1)
```
Total: 𝑛 · 𝑛 = **Θ(𝑛²)**.

Si el bucle interno depende del externo:

```python
for i in range(n):
    for j in range(i):    # i veces
        operacion()
```
Total: 0 + 1 + 2 + ... + (𝑛−1) = 𝑛(𝑛−1)/2 = **Θ(𝑛²)**.

## Bucle con `i *= 2`

```python
i = 1
while i < n:
    operacion()
    i *= 2
```
Los valores de `i` son 1, 2, 4, 8, ..., 2ᵏ. El bucle termina cuando 2ᵏ ≥ 𝑛, o sea 𝑘 = log₂ 𝑛.

Total: **Θ(log 𝑛)**.

## Combinación
Si ese bucle logarítmico está dentro de un `for` de 𝑛 iteraciones: 𝑛 · log 𝑛 = **Θ(𝑛 log 𝑛)**.
