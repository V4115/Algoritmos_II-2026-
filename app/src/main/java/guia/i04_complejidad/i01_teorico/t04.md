# 4. Ecuación de recurrencia de la búsqueda binaria y de Mergesort

## Búsqueda binaria
En cada paso se compara con el elemento del medio y se descarta la mitad del arreglo:

> **𝑇(𝑛) = 𝑇(𝑛/2) + 𝑂(1)**, con 𝑇(1) = 𝑂(1)

- Un subproblema (𝑎 = 1) de tamaño 𝑛/2 (𝑏 = 2).
- Trabajo fuera de la recursión: una comparación, 𝑂(1).
- Solución: **𝑇(𝑛) = 𝑂(log 𝑛)**.

## Mergesort
Divide el arreglo en dos mitades, ordena cada una recursivamente y las combina (merge) en tiempo lineal:

> **𝑇(𝑛) = 2𝑇(𝑛/2) + 𝑂(𝑛)**, con 𝑇(1) = 𝑂(1)

- Dos subproblemas (𝑎 = 2) de tamaño 𝑛/2 (𝑏 = 2).
- Trabajo fuera de la recursión: el merge, 𝑂(𝑛).
- Solución: **𝑇(𝑛) = Θ(𝑛 log 𝑛)**.
