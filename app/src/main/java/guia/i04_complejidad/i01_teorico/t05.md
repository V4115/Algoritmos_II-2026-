# 5. Resolvé 𝑇(𝑛) = 2𝑇(𝑛/2) + 𝑛 con el método de expansión

Caso base: 𝑇(1) = 1. Supongamos 𝑛 = 2ᵏ.

## Expansión

```
T(n) = 2T(n/2) + n

     = 2[ 2T(n/4) + n/2 ] + n
     = 4T(n/4) + n + n
     = 4T(n/4) + 2n

     = 4[ 2T(n/8) + n/4 ] + 2n
     = 8T(n/8) + n + 2n
     = 8T(n/8) + 3n
```

## Patrón general
Después de 𝑘 expansiones:

> 𝑇(𝑛) = 2ᵏ · 𝑇(𝑛/2ᵏ) + 𝑘 · 𝑛

## Llegar al caso base
𝑛/2ᵏ = 1 ⟹ 𝑘 = log₂ 𝑛. Reemplazando:

> 𝑇(𝑛) = 2^(log₂ 𝑛) · 𝑇(1) + 𝑛 · log₂ 𝑛
> 𝑇(𝑛) = 𝑛 · 1 + 𝑛 log₂ 𝑛

## Resultado

> **𝑇(𝑛) = 𝑛 log₂ 𝑛 + 𝑛 = Θ(𝑛 log 𝑛)**
