# 10. Ordená de menor a mayor crecimiento

𝑂(𝑛²), 𝑂(log 𝑛), 𝑂(𝑛 log 𝑛), 𝑂(1), 𝑂(2ⁿ), 𝑂(𝑛)

## Orden

> **𝑂(1) < 𝑂(log 𝑛) < 𝑂(𝑛) < 𝑂(𝑛 log 𝑛) < 𝑂(𝑛²) < 𝑂(2ⁿ)**

| Complejidad | Nombre |
|-------------|--------|
| 𝑂(1) | constante |
| 𝑂(log 𝑛) | logarítmica |
| 𝑂(𝑛) | lineal |
| 𝑂(𝑛 log 𝑛) | linealítmica |
| 𝑂(𝑛²) | cuadrática |
| 𝑂(2ⁿ) | exponencial |

Ejemplo con 𝑛 = 1024: 1 · 10 · 1024 · ~10 240 · ~1 048 576 · 2¹⁰²⁴ (un número de más de 300 dígitos).
