# 9. ¿Qué complejidad tiene el Fibonacci recursivo ingenuo y por qué? ¿Cómo mejorarla?

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

## Complejidad
Recurrencia:

> 𝑇(𝑛) = 𝑇(𝑛−1) + 𝑇(𝑛−2) + 𝑂(1)

Crece como la propia sucesión de Fibonacci: **𝑇(𝑛) = Θ(φⁿ)** con φ = (1+√5)/2 ≈ 1,618. Se suele acotar como **𝑂(2ⁿ)**: tiempo **exponencial**.

## Por qué
Hay **subproblemas superpuestos**: `fib(n-2)` se calcula dentro de `fib(n-1)` y también directamente, y así sucesivamente. El árbol de llamadas se ramifica en dos en cada nivel y repite los mismos cálculos una y otra vez.

## Cómo mejorarla

**1. Memoización (top-down), 𝑂(𝑛) tiempo y 𝑂(𝑛) espacio**
```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

**2. Programación dinámica iterativa (bottom-up), 𝑂(𝑛) tiempo y 𝑂(1) espacio**
```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
