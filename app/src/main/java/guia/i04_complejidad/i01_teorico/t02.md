# 2. Definí 𝑂, Ω y Θ. ¿Cuál se asocia al peor caso?

Sean 𝑓(𝑛) y 𝑔(𝑛) funciones positivas.

## Notación 𝑂 (cota superior)
𝑓(𝑛) ∈ 𝑂(𝑔(𝑛)) si existen constantes 𝑐 > 0 y 𝑛₀ tales que

> 𝑓(𝑛) ≤ 𝑐 · 𝑔(𝑛) para todo 𝑛 ≥ 𝑛₀

"𝑓 no crece más rápido que 𝑔".

## Notación Ω (cota inferior)
𝑓(𝑛) ∈ Ω(𝑔(𝑛)) si existen 𝑐 > 0 y 𝑛₀ tales que

> 𝑓(𝑛) ≥ 𝑐 · 𝑔(𝑛) para todo 𝑛 ≥ 𝑛₀

"𝑓 crece al menos tan rápido como 𝑔".

## Notación Θ (cota ajustada)
𝑓(𝑛) ∈ Θ(𝑔(𝑛)) si 𝑓(𝑛) ∈ 𝑂(𝑔(𝑛)) **y** 𝑓(𝑛) ∈ Ω(𝑔(𝑛)), es decir, existen 𝑐₁, 𝑐₂ > 0 y 𝑛₀ tales que

> 𝑐₁ · 𝑔(𝑛) ≤ 𝑓(𝑛) ≤ 𝑐₂ · 𝑔(𝑛) para todo 𝑛 ≥ 𝑛₀

"𝑓 crece exactamente como 𝑔".

## ¿Cuál se asocia al peor caso?

**𝑂**, porque da una **cota superior**: garantiza que el algoritmo nunca tarda más que eso. Por eso, cuando se habla del peor caso, se suele expresar con 𝑂. Ω se asocia al mejor caso (cota inferior).

> Aclaración: 𝑂, Ω y Θ son cotas sobre funciones; "peor/mejor/promedio" son escenarios de entrada. Se puede dar 𝑂 y Ω de cualquiera de los tres casos, pero la asociación habitual es 𝑂 ↔ peor caso, Ω ↔ mejor caso.
