# 6. ¿Para qué sirve una lista circular y qué cuidado hay que tener al recorrerla?

En una lista circular el **último nodo apunta al primero** (en vez de a `null`), así que no hay "final": se puede seguir dando vueltas indefinidamente.

```
 ┌─────────────────────┐
 ↓                     │
[ a ] → [ b ] → [ c ] ─┘
```

## Para qué sirve
- **Planificación round-robin** (turnos de CPU entre procesos).
- **Juegos por turnos** (rotar entre jugadores).
- **Buffers circulares** (colas de tamaño fijo, streaming).
- **Listas de reproducción en bucle**.
- Cualquier situación en la que, al llegar al final, se vuelve naturalmente al principio.

## Cuidados al recorrerla
1. **No hay `null` que marque el final**: un `while (actual != null)` es un **bucle infinito**. Hay que cortar al **volver al nodo de partida** o contando hasta `size` elementos.
2. Usar `do-while`, para que el primer nodo se procese al menos una vez:

```java
Nodo actual = primero;
if (actual != null) {
    do {
        procesar(actual.dato);
        actual = actual.siguiente;
    } while (actual != primero);
}
```

3. Contemplar los **casos borde**: lista vacía y lista de un solo nodo (que se apunta a sí mismo).
4. Al insertar o eliminar el primero o el último, **mantener el enlace último → primero**.
