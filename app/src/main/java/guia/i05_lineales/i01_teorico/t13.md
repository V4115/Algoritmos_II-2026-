# 13. ¿Qué operaciones agrega ListIterator sobre Iterator? ¿Cuándo usarías cada uno?

## `Iterator<E>` (cualquier `Collection`)
- `hasNext()`
- `next()`
- `remove()` (opcional)

Solo avanza, hacia adelante.

## `ListIterator<E>` (solo `List`) — extiende `Iterator`
Agrega:

| Operación | Qué hace |
|---|---|
| `hasPrevious()` / `previous()` | Recorrer **hacia atrás** |
| `nextIndex()` / `previousIndex()` | Conocer los **índices** vecinos |
| `set(E e)` | **Reemplazar** el último elemento devuelto |
| `add(E e)` | **Insertar** un elemento en la posición actual |

Además se puede crear en una posición arbitraria: `lista.listIterator(i)`.

## Cuándo usar cada uno
- **`Iterator`**: recorrido simple hacia adelante, o cuando la colección **no es una lista** (por ejemplo un `Set`). También sirve para eliminar mientras se recorre.
- **`ListIterator`**: cuando se necesita **ir hacia atrás**, **modificar o insertar elementos durante el recorrido**, o saber en qué posición se está.

```java
ListIterator<String> it = lista.listIterator();
while (it.hasNext()) {
    String s = it.next();
    if (s.isEmpty()) it.set("(vacío)");   // reemplaza
}
```
