# 10. ¿Qué diferencia hay entre HashSet, LinkedHashSet y TreeSet?

Los tres implementan `Set` (sin repetidos), pero difieren en **estructura interna, orden y costo**.

| | HashSet | LinkedHashSet | TreeSet |
|---|---|---|---|
| Estructura | Tabla hash | Tabla hash + lista doblemente enlazada | Árbol rojo-negro |
| Orden al iterar | **Ninguno garantizado** | **Orden de inserción** | **Ordenado** (orden natural o `Comparator`) |
| `add` / `contains` / `remove` | 𝑂(1) promedio | 𝑂(1) promedio | **𝑂(log 𝑛)** |
| Acepta `null` | Sí (uno) | Sí (uno) | No (con orden natural) |
| Requiere | `equals` y `hashCode` | `equals` y `hashCode` | `Comparable` o `Comparator` |
| Memoria | Menor | Algo mayor | Mayor (nodos del árbol) |

## Cuándo usar cada uno
- **`HashSet`**: solo importa la pertenencia y la velocidad.
- **`LinkedHashSet`**: además se necesita **conservar el orden en que se agregaron** los elementos.
- **`TreeSet`**: se necesitan los elementos **ordenados** o consultas de rango/vecinos (`first()`, `last()`, `floor()`, `ceiling()`, `subSet()`).
