# 12. ¿Por qué recorrer una lista enlazada con for + get(i) es 𝑂(𝑛²)? ¿Cómo lo evita el iterador?

## El problema

```java
for (int i = 0; i < lista.size(); i++) {
    procesar(lista.get(i));   // en LinkedList, get(i) es O(n)
}
```

Cada `get(i)` **empieza de nuevo desde un extremo** y avanza `i` nodos (en `LinkedList`, desde el extremo más cercano). El total es:

> 0 + 1 + 2 + ... + (𝑛−1) = 𝑛(𝑛−1)/2 = **𝑂(𝑛²)**

Se recorre una y otra vez el mismo camino.

## Cómo lo evita el iterador

```java
for (T x : lista) {          // usa un Iterator por debajo
    procesar(x);
}
```

El iterador **guarda la posición actual** (una referencia al nodo en el que está). `next()` solo sigue un puntero al nodo siguiente → **𝑂(1)** por paso, y el recorrido completo queda en **𝑂(𝑛)**.

> Con `ArrayList` no hay diferencia asintótica, porque `get(i)` es 𝑂(1). Pero escribir el código con iterador / for-each funciona bien con **cualquier** implementación de `List`.
