# 8. Asociá cada estructura vista con su equivalente en la API de Java

| Estructura / TDA | Equivalente en Java |
|---|---|
| Vector dinámico | `java.util.ArrayList` (`Vector` es la versión legacy) |
| Lista doblemente enlazada | `java.util.LinkedList` |
| Lista simplemente enlazada | No hay clase propia en el JDK (`LinkedList` es doble) |
| Lista circular | No hay equivalente directo (se implementa a mano o se simula) |
| Interfaz de lista (TDA Lista) | `java.util.List` |
| Conjunto (TDA) | `java.util.Set` |
| Conjunto sobre tabla hash | `HashSet` |
| Conjunto con orden de inserción | `LinkedHashSet` |
| Conjunto ordenado (árbol) | `TreeSet` |
| Recorrido secuencial | `Iterator` |
| Recorrido bidireccional de listas | `ListIterator` |
| Pila | `Deque` / `ArrayDeque` (`Stack` es legacy) |
| Cola | `Queue` / `ArrayDeque` / `LinkedList` |

Todas pertenecen al **Java Collections Framework**, y las colecciones implementan `Iterable`, por lo que se pueden recorrer con `for-each`.
