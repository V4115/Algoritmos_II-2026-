# 4. ¿Por qué acceder por índice es 𝑂(1) en el vector y 𝑂(𝑛) en la lista enlazada?

## Vector
Está respaldado por un arreglo, con elementos **contiguos y del mismo tamaño**. La posición se calcula con aritmética directa:

> dirección(`i`) = dirección_base + `i` × tamaño_elemento

Un cálculo y un acceso a memoria → **𝑂(1)** (acceso aleatorio).

## Lista enlazada
Los nodos están **dispersos** en memoria y lo único que se conoce es el primero. No hay forma de saltar al nodo `i`: hay que **seguir los punteros `siguiente` uno por uno**, `i` veces:

```java
Nodo actual = primero;
for (int k = 0; k < i; k++) {
    actual = actual.siguiente;
}
```

En el peor caso recorre los 𝑛 nodos → **𝑂(𝑛)** (acceso secuencial).

(En una lista doblemente enlazada se puede arrancar desde el extremo más cercano, pero sigue siendo 𝑂(𝑛).)
