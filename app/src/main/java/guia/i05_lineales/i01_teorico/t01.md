# 1. ¿Qué diferencia hay entre el tamaño y la capacidad de un vector dinámico?

- **Tamaño (`size`)**: cantidad de elementos que el vector tiene **realmente almacenados**. Son los que el usuario ve (índices `0` a `size-1`).
- **Capacidad (`capacity`)**: cantidad de posiciones del **arreglo interno** que se reservaron. Es cuánto cabe antes de tener que agrandarlo.

Siempre se cumple: **`size ≤ capacity`**.

```
capacidad = 8
[ 4 | 7 | 1 | 9 | _ | _ | _ | _ ]
  size = 4
```

Cuando `size == capacity` y se quiere agregar otro elemento, hay que pedir un arreglo nuevo más grande y copiar los elementos (ver pregunta 2).

En Java, `ArrayList.size()` devuelve el tamaño; la capacidad no se consulta directamente (solo se puede influir con `ensureCapacity()` y `trimToSize()`). `Vector` sí tiene `capacity()`.
