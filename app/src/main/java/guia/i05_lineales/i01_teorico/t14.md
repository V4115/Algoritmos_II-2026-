# 14. ¿Cuál es la única forma segura de eliminar elementos mientras recorrés una lista? ¿Qué excepción aparece si lo hacés mal?

## Forma segura: `remove()` **del iterador**

```java
Iterator<Integer> it = lista.iterator();
while (it.hasNext()) {
    Integer x = it.next();
    if (x % 2 == 0) {
        it.remove();   // ✅ elimina el último elemento devuelto por next()
    }
}
```

El iterador sabe que la lista cambió, porque la modificación pasa por él, y mantiene su estado interno consistente.

> Alternativa moderna equivalente: `lista.removeIf(x -> x % 2 == 0);` (usa internamente el mecanismo seguro).

## Forma incorrecta: modificar la lista directamente durante un for-each

```java
for (Integer x : lista) {
    if (x % 2 == 0) {
        lista.remove(x);   // ❌ ConcurrentModificationException
    }
}
```

## Excepción
**`java.util.ConcurrentModificationException`**. Los iteradores de `ArrayList`/`LinkedList` son *fail-fast*: la lista lleva un contador de modificaciones (`modCount`) y el iterador lo compara en cada `next()`. Si cambió sin que lo hiciera el propio iterador, lanza la excepción.

## Trampa extra
Eliminar con un `for` por índice **no lanza excepción**, pero al eliminar en `i` los elementos se corren y **se saltea el siguiente**. Hay que recorrer hacia atrás o ajustar el índice (`i--`).
