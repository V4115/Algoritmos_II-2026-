# 5. ¿Qué ventaja aporta una lista doblemente enlazada frente a la simple?

Cada nodo tiene, además de `siguiente`, una referencia **`anterior`**.

```
null ← [ a ] ⇄ [ b ] ⇄ [ c ] → null
```

## Ventajas
1. **Recorrido en ambos sentidos** (hacia adelante y hacia atrás).
2. **Eliminar un nodo conocido en 𝑂(1)**: con la lista simple hace falta el predecesor, que hay que buscar recorriendo (𝑂(𝑛)). En la doble, el nodo sabe quién es su anterior.
3. **Insertar antes de un nodo dado en 𝑂(1)**, por lo mismo.
4. **Eliminar el último elemento en 𝑂(1)** si se guarda referencia a la cola (en la simple es 𝑂(𝑛) porque hay que llegar al penúltimo).
5. **Acceso por índice un poco mejor**: se puede empezar desde el extremo más cercano (𝑛/2 pasos como máximo, aunque sigue siendo 𝑂(𝑛)).

## Costos
- **Más memoria**: un puntero extra por nodo.
- **Más trabajo al insertar/eliminar**: hay que mantener consistentes dos punteros por enlace (más fácil cometer errores).

`java.util.LinkedList` es doblemente enlazada.
