# 7. ¿Qué caracteriza al TDA Conjunto? ¿Por qué agregar es 𝑂(𝑛) en una implementación sobre lista?

## Qué lo caracteriza
Un **Conjunto** es una colección de elementos:

- **Sin repetidos**: cada elemento aparece como máximo una vez.
- **Sin orden ni posiciones relevantes**: no se accede por índice; importa la **pertenencia**.

Operaciones típicas: `agregar`, `eliminar`, `pertenece`, `tamaño`, `esVacio`, y operaciones entre conjuntos (**unión, intersección, diferencia**).

## Por qué `agregar` es 𝑂(𝑛) sobre una lista
Para respetar la propiedad "sin repetidos", antes de insertar hay que **verificar que el elemento no esté ya**. En una lista eso es una **búsqueda lineal**:

```java
public void agregar(T x) {
    if (!pertenece(x)) {   // recorre la lista: O(n)
        lista.agregarAlFinal(x); // O(1) si hay referencia a la cola
    }
}
```

> 𝑂(𝑛) (buscar) + 𝑂(1) (insertar) = **𝑂(𝑛)**

La inserción en sí es barata; lo caro es **chequear la pertenencia**. Por eso se usan estructuras que aceleran `pertenece`: tabla hash (𝑂(1) promedio) o árbol balanceado (𝑂(log 𝑛)).
