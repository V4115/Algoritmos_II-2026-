# Teórica 07

**¿Para qué sirve un enum? ¿Qué ventaja tiene sobre usar cadenas de texto?**

Un enum sirve para representar un conjunto limitado y predefinido de valores que no deberían cambiar. Por ejemplo, los días de la semana, estados de un pedido o niveles de prioridad.
La ventaja sobre usar cadenas (String) es que el enum evita errores de escritura y hace que el código sea más seguro y claro. Por ejemplo, con String podríamos escribir "sabado", "SABADO" o "sabdao" y serían valores diferentes. Con un enum, solamente se pueden utilizar los valores definidos.

Además, un enum  no solo puede tener métodos y atributos propios, por lo que permite asociar comportamiento a cada valor, sino que las comparaciones entre enums (por ejemplo, con == o en estructuras switch) son comparaciones de punteros o enteros, lo cual es internamente más rápido y eficiente que comparar caracteres de texto (String matching).
